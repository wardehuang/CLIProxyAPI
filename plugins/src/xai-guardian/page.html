2. 保活与复活

保活复查健康、已连通和冷却中节点；复活只领取异常节点。两者都不调用后台账号检查。

3. 健康槽位

健康节点按最近检查时间分配 primary 与 candidate 槽位；过期节点不进入槽位。

4. 实时守护

CPA 核心执行流式判定；这里保存首字、生成、空闲和 thinking evidence 阈值。

IP 列表、保活、复活、健康槽位和实时守护使用 guard 数据域；账号状态后台快照单独维护。页面不读取、接收或保存 Management key、xAI 凭据。

增加IP

每一行录入一个代理节点；必须包含 host 和 port。支持代理 URL 中的认证信息，按原插件明文展示。

支持 http、https、socks5、socks5h URL，可选 username:password@；也支持 host:port、host,port,protocol、host:port,出口IP,port,protocol。只填裸 IP 无法录入。格式错误行不会写入数据库。
